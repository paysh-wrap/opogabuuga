## Before EVERY session (Asia/ETH open, London, RTH — same routine; RTH also adds gamma exposure)
1. Previous RTH profile: TPO + volume profile + delta profile (30-min chart; candles irrelevant). Mark prior-RTH VAH / VAL / POC; weekly TPO/VA if relevant.
2. Trending vs balance: are we trading above/below the weekly distribution? Mark single-print areas = LVN (little time spent).
3. CONTEXT = where price accepts relative to the previous RTH value area at the new session open:
   - accepted ABOVE prev-RTH VA (time above, consolidation above, no sharp rejections back in) → BULLISH context → longs only, NO shorts.
   - accepted BELOW → BEARISH → shorts only. Inside VA / two-sided → BALANCE → trade only edges with caution (or stand aside).
   - Context flips only on clear acceptance the other way; until then counter-trend trades are skipped even with order-flow confirmation.

## Entry trigger (last): trapped sellers/buyers + ABSORPTION read on CVD/footprint at that key level, then buying/selling resumes → enter with the context.
Example: seller trapped below ETH VWAP at London open → rip back above delta outlier + prior-session high → pullback, second trapped seller, absorption → long.
