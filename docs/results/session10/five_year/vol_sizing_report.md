# Volatility-scaled sizing (agentF)
Script: volsize.py (own copies of funded_path/eval_path with per-day contracts; results.json has all numbers).
Vol = std of last N (14/20) RTH close-to-close returns of MNQ 1m bars, dated strictly before day D. Contracts = clamp(round(base*target/vol),1,base+2).
Target = median vol of prior 365 days (prior1y; expanding median if <60 obs) or in-sample 2021-11..2023-12 median (insample).
5 accounts, payout every 10 sessions, funded 260 / eval 250 sessions, starts every 2. H1 = starts <2024-01 (n=283), H2 = starts >=2024-01 (n=240).
Baselines reproduce exactly (881/21072/23.5, 952/23706/26.8, 643/16025/26.0).
Verdict: NONE adopted. See final message table.
