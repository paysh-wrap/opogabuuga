- **Costs:** 1 micro, $1.00 RT (MGC $1.60) + 1 tick on every entry, stop and flat exit, stop-first inside a 1m bar; same as sessions 9-18. NOISE baseline = session-17 **preset C** ($250 stop, +100 pt lock -> entry +10, hourly checks 10:00-15:00, max 3/day). It reproduces the committed numbers exactly (HO24: 427 trades, 52.2 %, +$27.19, PF 1.43, max DD $2,028; J full year = 149 trades, 55 %, PF 1.53, +$39.3, net $5,857).
- **Eval sim (Lucid Pro, EOD trailing MLL, lock at +MLL+100, target per size 1,250/3,000/6,000/9,000, soft DLL 1,200/1,800/2,700 on 50/100/150K, none on 25K eval; pass-in-one-day allowed, no consistency):** block bootstrap (10-day blocks, 600 paths, 400 sessions) of the era's real days. `PASS / BUST` are bootstrap %. Pro 25K = 1 micro, Pro 50K = 2 micros (app default size table). Streams are scaled linearly by contracts (costs scale too).
- **J is small.** 149 NOISE trades in 12 months; a random-direction version of NOISE (same timing, exits, lock) scores J PF 1.13, +$11.5/trade on average, and its J bootstrap pass ranges from 19 % to 64 % across seeds (median about 50 %). So a +/-5 pt PASS difference on J is inside the noise; I therefore also require IS agreement.
- **Decision rule (written before looking at J):** ADOPT only if J is better (PF up, $/trade >= base, boot pass >= base and bust <= base, net >= 97 % of base) AND IS is not worse by much (PF >= base-0.03, $/trade >= base-0.5, net >= 85 % of base, boot pass/bust within 1 pt). Otherwise reject. The CLAUDE.md win-rate/profit rule (never lower measured win rate or profit) is applied through the net-profit test.
